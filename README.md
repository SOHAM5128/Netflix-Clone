# Netflix Landing Page Clone

A responsive Netflix-inspired streaming platform UI built using HTML, CSS, and Vanilla JavaScript. This project recreates the Netflix landing page experience with a modern interface and interactive features.

## Features

- **Responsive Navbar**: Navigation bar that adapts to all screen sizes.
- **Language Selector**: Interface option to select languages.
- **Hero Section**: Sleek landing section with dynamic backgrounds and email CTA.
- **Email Validation**: Dynamic input validation for signing up/getting started.
- **Trending Movies**: Dynamic trending movie carousel.
- **FAQ Accordion**: Fully interactive accordion for frequently asked questions.
- **CTA Section & Responsive Design**: Seamless viewing experience on mobile, tablet, and desktop.
- **Modular Structure**: Organized codebase using modern ES6 JavaScript modules and scoped CSS files.

## Technologies

- HTML5
- CSS3
- JavaScript ES6 (ES6 Modules)
